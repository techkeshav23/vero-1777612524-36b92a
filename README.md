## ✨ Features
- **Immersive Hero Section**: A cinematic, full-screen video experience that captures the artistry of pasta preparation with a high-conversion reservation CTA.
- **Interactive Menu**: A beautifully categorized digital menu featuring high-resolution photography and detailed ingredient highlights for a premium dining preview.
- **Reservation Engine**: A seamless, user-centric booking interface designed to handle party sizes and timing with instant confirmation logic.
- **Premium Design System**: Sophisticated serif typography, parallax scrolling effects, and elegant micro-interactions that mirror a luxury dining atmosphere.

## 🛠 Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion (for fluid animations)

## 🏃 Quick Start
```bash
git clone
```

## 🏗 Architecture
The project follows a modular architecture within the Next.js App Router, utilizing a `components/` directory for reusable UI elements like the reservation form and menu cards. Page-specific logic is encapsulated in the `app/` directory, ensuring a clean separation of concerns between layout structure and content-heavy sections.
